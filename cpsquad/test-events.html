Setup Google Drive Fetch:

  1. Go to Google Cloud Console
  2. Create project and enable Google Drive API
  3. Create API Key in Credentials
  4. Add to .env.local: GOOGLE_DRIVE_API_KEY=your_key
  5. Run: cd app/lib && node fetchEventImages.js
  6. Click "Load from JSON File" above to see results
